# Can the reader attach both amounts to events?

Use the previous repeated-addition cases for development. Freeze the new reader, scorer and independent synthetic test banks before opening the held-out wording. Give each reader only the user's text. Preserve the public addition-then-multiplication contract and allow at most two arithmetic step checks per request. The experiment runs offline.

The primary bank has six cases in each group: two descriptions of one addition, two separate confirmed additions, unresolved identity or occurrence, and outside controls. For the 18 relevant requests the case author marks both numeric mentions and one or more acceptable nearby expressions identifying each event. Score the positions in the original string. Two identical words in different clauses are different evidence. A numeric mention needs the annotated span exactly. Its event phrase must contain a complete annotated anchor with at most two additional words and six words total. Report individual links out of 36, both links per request out of 18, and both links plus the correct relationship. A deferral can retain correctly identified links.

Compare the new reader's relationship decisions with the previous wording reader and three integer-run policies that merge, count twice, or ask when any consecutive numeric mentions match. Those policies defer when no run occurs. For a comparison that can also identify event words, give a proximity rule the very same numeric positions found by the new reader. It picks the nearest content word without crossing a sentence end, semicolon or line break, favoring the following word in a tie. It gets no annotated positions or event labels. Also swap the reader's two event spans, keeping the amounts fixed, to check that the score distinguishes which event text was attached to which mention.

Only a decision that the two mentions are one addition can attempt the public arithmetic check. Record correct releases, incorrect releases, releases outside scope, receipts, questions and deferrals. Separately report whether both links supported each otherwise-correct release. The independent boundary bank includes supported restatements and misleading contexts. Review the actual wording of each new question for relevance.

For diagnosis, rerun only the nearest-word rule with the annotated amount positions supplied. This measures how much locating the numbers limits that particular baseline. The deployed readers never receive those positions.

Evidence of progress requires at least one more correctly linked pair than proximity, a correct relationship on a fresh linked pair, and a correctly grounded checked restatement. Any incorrect or outside-scope release in either bank rules out activation. This is a small descriptive trial.
