# Building a local action vocabulary from observations

This research trial starts with unnamed behavior and arbitrary action names. The experimenter provides the observable inputs, the allowed elementary rules, bounded examples, and a separate source of truth. The learner must build its own bindings within each world. Names do not carry a global interpretation. No language model participates.

**Trial 1.** Freeze six independently constructed worlds (case-file SHA-256 `c675372f44cb33ee5a2109a683bccc0ef074db907418cfe36417b2f50f75fe6a`). Four use integer maps `a*x+b`. One contains a nonlinear exception. Another has a conflicting observation. Each has three opaque action names, one initial observation per name, one feedback observation, two reserved validation observations per name, and eight held-out single or composed requests of up to three moves. Never report the first guess as independently checked. Record how often first guesses disagree with new feedback, how many change, whether a previously correct sibling survives, full-trace accuracy and refusals on the held-out requests. Compare exact example lookup, the provisional first guess, and the checked domain after feedback. Only the checked arm may report validated results. A pure checker must reject an altered intermediate even if a proposed sequence ends on the correct value.

**Trial 2.** The learner receives three anonymous binary readings and an action on an integer. A candidate effect is either a constant delta from −2 to +2 or a delta that depends on one reading. Test 16 worlds (seed 742091), including four constant, eight single-feature, two interactions, and two with inconsistent results for an identical visible input. In each world there are eight possible training observations. Withhold their outcomes until the chosen probe is spent. Compare fixed order versus choosing the probe with the smallest worst remaining hypothesis group. Repeat at two, three and four paid probes per world. Also try a fixed, constant-only learner. These runs are separate, each starting empty. Grant each arm the same nine reserved validation observations per world. Use them only to veto an already uniquely identified law. Count unused validation readings separately. Eight fresh endpoint tests per world cover all feature patterns with different starting values. The simulator supplies truth and never selects a rule for the learner.

Better probe selection must improve independently validated coverage over fixed order at the same training budget without introducing wrong releases. Report the limitation if the candidate language lacks the true rule or if no deterministic function can explain the observed state. No change to the installed arithmetic contract is part of these trials.

For the scalar family also compare direct two-point interpolation with the same validation veto. Count full-trace errors after feedback with that veto switched off. In the context study count candidate effect predictions used to rank the menu, including ties, independently from paid instrument observations. The full confirmatory sweep is intentionally charged separately from learning.
